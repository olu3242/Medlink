# Wave Transition Runbook

## Purpose

Prepare and authorize a future MedLink wave without implementing its business
scope before admission.

## Procedure

1. Register the wave, owner, dependencies, admission and exit criteria,
   certification requirements, and change history.
2. Register affected capabilities with runtime, API, data, certification, and
   operational readiness traceability.
3. Select only certified extensions whose semantic contract versions are valid.
4. Publish audience-specific SDK/API compatibility guarantees.
5. Convert each roadmap item into a governed initiative.
6. Complete architecture review, risk assessment, approval, implementation,
   certification, rollout planning, measurement, and knowledge capture.
7. Submit immutable evidence for all five framework gates.
8. Keep admission blocked until RC1 operational certification and executive wave
   approval evidence are both independently verified.

Framework readiness does not grant permission to implement or deploy Wave 2.5.
